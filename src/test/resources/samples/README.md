# Camera sample files

Small real files from many cameras and phones, used by `CameraSamplesTest` to check that writing a location keeps
everything else (maker notes included) intact.

They come from the test suite of [ExifTool](https://exiftool.org/) (`t/images` in
https://github.com/exiftool/exiftool), where the image data was cut down so the files stay tiny:
